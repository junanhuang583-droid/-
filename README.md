# 炉石制造

纸面卡牌游戏电子化项目。

当前目标是忠实还原原纸牌游戏规则，并优先支持：

- 浏览器基础验收版
- 同一设备双人轮流对战
- 经典共享总牌库模式
- 后续再扩展电脑对手、完整特殊效果、构筑模式、联网与更多平台能力

## 当前设计基线

- `docs/卡牌游戏记录_v0.5.md`
- Rules Core v1
- 77 种正式随从
- 2 种衍生随从

实现原则：**卡牌数据与游戏规则分离**。卡牌只描述自身数据与效果声明；通用规则由规则引擎统一实现。

## v0.2 浏览器基础验收版

当前网页只执行最基础的对局规则，所有随从特殊效果暂不执行。

已实现：

- 双方80点生命
- 共享牌库、初始8张手牌、每回合摸牌、后手首次额外摸1张
- 每方5个随从位
- 每回合最多普通召唤1只随从
- 普通随从上场当回合不能攻击
- 每只普通随从每回合攻击1次
- 可攻击敌方随从或英雄
- 攻击方不会受到反击伤害
- 随从死亡进入所属玩家弃牌堆，并记录死亡日志
- 英雄生命归零判胜负
- 本地双人交接屏，交接时隐藏下一位玩家手牌
- 对局操作日志

暂未实现：

- 所有随从特殊效果和关键词，包括快攻、迅疾、嘲讽、亡语等
- 卡牌专属召唤条件
- 进化、进化石、超级进化石
- 装备、场景、陷阱及其他卡牌类型
- AI 对手

## 持久化

浏览器版不会每次打开都创建新局。

- 每次改变对局状态后立即保存
- 每5秒进行一次保险保存
- 页面切到后台或隐藏时保存
- 关闭标签页/浏览器时保存
- 保存当前存档和上一份备份
- 同一浏览器多个标签页可同步较新的存档

当前存档保存在浏览器本地，因此同一浏览器、同一设备重新打开网站可以继续之前的对局。更换浏览器、设备，或主动清除该网站的浏览器数据时不会自动迁移存档。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm test
npm run build
```

## 目录

```text
docs/          设计记录与规则基线
src/model/     游戏领域类型
src/core/      通用规则与基础对局引擎
src/data/      卡牌记录解析
src/web/       浏览器界面与持久化
tests/         自动测试
```

GitHub Actions 已配置自动构建和 GitHub Pages 发布。仓库首次使用 Pages 时仍需要仓库管理员在 GitHub 中启用 Pages；启用后后续推送会自动重新构建和发布。
