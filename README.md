# 炉石制造

纸面卡牌游戏电子化项目。

当前目标是忠实还原原纸牌游戏规则，并优先支持：

- 玩家 vs 电脑
- 同一设备双人轮流对战
- 经典共享总牌库模式
- 后续再扩展构筑模式、联网与更多平台能力

## 当前设计基线

- `docs/卡牌游戏记录_v0.5.md`
- Rules Core v1
- 77 种正式随从
- 2 种衍生随从

实现原则：**卡牌数据与游戏规则分离**。卡牌只描述自身数据与效果声明；通用关键词、回合、召唤、死亡、攻击、场地等规则由规则引擎统一实现。

## 第一阶段目录

```text
docs/          设计记录与规则基线
src/model/     游戏领域类型
src/core/      通用规则核心
src/data/      卡牌数据与解析/生成逻辑
scripts/       开发期数据生成脚本
```

当前处于代码骨架阶段，尚未锁定 UI 技术栈。核心规则层保持与 UI 解耦，方便后续接 Web / 桌面 / 移动端界面。
