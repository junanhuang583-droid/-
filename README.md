# 炉石制造 / Card Game

自制纸面卡牌的浏览器电子化原型。当前以固定视角战场、共享牌库和本地热座为主，支持PC/手机浏览器；电脑AI、完整卡牌能力和桌面封装仍在后续计划中。

## 开发与验收

```sh
npm ci
npm run dev
# 规则 / 类型 / 构建
npm run check
# 完整生产页面浏览器验收，含Pages子路径及离线壳
npx playwright install --with-deps chromium
npm run test:browser
```

`npm run build` 会先校验重建战场和结束回合资产，再构建JS/CSS，最后生成版本化完整离线壳。不得删除分块与SHA校验流程。存档仍兼容原v1键，游戏状态统一由GameStore管理。

## 实现状态

基础生命、回合、通常4张/后手首次5张抽牌、5格、扣血/献祭召唤、攻击及部分关键词/亡语已有实现。部分定点亡语与控制目标经统一规则入口处理。进化、超级进化石发放、装备、场景、其他高级能力、AI尚未完整实现。演示普通攻击与进化石牌能查看，不代表效果可执行；包含未实现系列石条件的召唤不得跳过条件。

未知数量的正式随从只在演示牌池临时按1张，绝不写回正式记录。共享牌库合并双方弃牌回收仍为待确认的临时策略。多单位同时死亡的完整归属方顺序选择尚未实现。

## 当前停止点

地图重制前工程基线。原战场、正式卡背不变。下一美术阶段是左右一起设计的战场V2，而不是继续用CSS假凹槽“融合”。本仓库原型卡牌外观不等于最终A～H结构化卡牌施工已经完成。
