# 纸面卡牌游戏｜规则与卡牌记录 v0.5

记录日期：2026-09-10  
状态：第五版完整累计记录，包含77种正式随从、2种衍生随从；基础规则已封装为 Rules Core v1。

本版依据v0.4及其后用户直接输入、纠错整理。此前手写图片识别的猜测不作为正式卡牌数据；已上传原画只作视觉参考，除用户明确口述外，不从图片自行补写技能。

## 1. 项目范围与记录原则

本项目将用户读书时期自行手写、绘制的纸面卡牌游戏忠实电子化。原版实际对战曾持续一个多小时，初版不根据表面数值或其他卡牌游戏的习惯擅自重做平衡。

- 初版目标：玩家对电脑，以及一台手机上两人轮流对战。联网、服务器、API和聊天对战集成以后再考虑。
- 已放弃的羁绊体系暂不参与游戏和数值计算。随从卡左上角保留的羁绊标记暂时忽略，原始图片另行保留。
- 用户亲自输入及明确纠正的内容优先于此前图片识别或助手推测。未说明的机制不按炉石传说、云顶之弈等游戏自动补全。
- “交换”按“召唤”、“王宇”按“亡语”处理，属于用户明确确认的语音输入纠错。其他明显笔误可结合上下文处理，但名称、数值、前置条件等有实际歧义时应保留待确认项。
- “未提供”不等于0、不等于1张，也不等于不存在。没有写召唤条件则直接召唤，这一条是明确的基础规则。
- 编号C001～C077为整理编号，不代表原卡编号。衍生随从使用T编号，不计入正式卡牌种类。
- 本文是完整累计记录，不是只包含本次新增的补丁；旧版本保留供追溯。

## 2. 已确认的基础规则（Rules Core v1）

本节为当前电子化实现可直接采用的基础规则核心。若后续牌面专属规则与本节冲突，以明确写在牌面上的更高优先级或例外规则为准。

### 2.1 对局、共享牌库、抽牌与先后手

- 双方各80点初始生命值。将对方生命降到0即获胜；双方同时降到0判定平局。
- 经典模式沿用原纸牌规则：双方从同一个“总牌库”摸牌，不是各自提前组一副独立牌库。
- 双方初始手牌各8张，手牌无上限。
- 正常每回合摸4张。后手仅第一次摸牌时多摸1张，即第一次摸5张；之后恢复每回合4张。
- 后手额外获得1颗普通进化石。
- 开局双方各获得1颗“超级进化石”。电子版中它属于开局额外发放的特殊卡，不从共享牌库抽取；原纸牌版牌库中实体只有1张不影响电子版双方各获得1张。
- 超级进化石：使用后可以无视任意随从自身的召唤条件，直接召唤1只任意随从。其与场地上限等通用规则若发生特殊冲突，仍以未来明确规则为准。
- 共享牌库抽空后，将已弃掉的牌重新洗回牌库继续抽，不设疲劳伤害。双方弃牌堆在对局逻辑上相互独立；重新洗回时双方弃牌如何归并到共享牌库，待程序实现时最后确认。
- 电子版以后可以新增“构筑模式”，允许玩家自行组牌；但初版经典模式优先忠实还原共享总牌库玩法。

### 2.2 出牌、场地与召唤限制

- 每方常规最多存在5只占用随从位的随从。
- 正常情况下每回合最多“普通召唤”1只随从。
- 除普通随从召唤数量限制外，没有统一的出牌数量限制。满足牌面条件即可连续使用其他卡牌，不额外添加法力值、费用上限或每回合出牌张数限制。
- 未写召唤条件的随从可以直接召唤；写明扣血、献祭、进化石、前置随从等要求的，按牌面执行。
- 召唤扣除自身生命可以将自己扣死。
- 效果召唤、复活、亡语产生的随从以及进化，不占“每回合普通召唤1只”的次数。
- 特殊效果允许临时突破5只随从的常规上限。忍者分身明确不占5只随从上限。
- 亡语产生随从时，原随从已经死亡并进入弃牌堆，因此通常会自然腾出原本位置。
- 场上位置具有顺序与左右相邻关系，用于祝福剑、岩盾、定海、船炮等位置型技能。电子版初版按固定5个随从位实现。

### 2.3 进化、献祭、死亡与弃牌堆

- 进化要求被进化的原随从已经在己方场上，并满足对应卡牌要求。
- 一回合内进化数量不限。
- 进化成功后，原卡进入己方弃牌堆，进化后的随从接替进入场上。用户目前只明确“献祭算死亡”；进化是否属于死亡、是否触发亡语尚未被单独明确，因此程序实现前不得擅自让进化触发亡语。
- 献祭只能选择己方场上的随从。
- 献祭算死亡：被献祭随从进入弃牌堆，并正常触发亡语。
- 双方弃牌堆相互独立，复活、查找“己方上一只死亡随从”等效果按己方弃牌与死亡记录处理。
- 多只己方随从同时死亡时，该批亡语的发动顺序由这些随从的归属方决定。
- 当双方同一时点均有普通自动效果需要结算时，默认当前回合玩家优先；若某技能或效果明确写明在对方回合发动，则该类跨回合触发效果优先。
- 必杀：由必杀造成的死亡无法复活，优先级高于所有其他复活效果。

### 2.4 随从、攻击与生命

- 随从具有生命值及攻击数值，卡面“X伤/回”按普通攻击伤害记录，不是每回合自动造成X点伤害。卡面圆圈代表随从生命值。
- 普通随从上场当回合不能攻击，从之后的回合开始正常每回合攻击1次。
- 随从攻击时，被攻击目标扣血，攻击方本身不受到反击伤害，除非特殊效果另有规定。
- 没有嘲讽或其他目标限制时，随从可以自由选择攻击敌方随从或直接攻击敌方英雄。
- 随从受伤后的剩余生命持续保留，不会在回合结束时自动恢复，除非恢复等特殊效果另有规定。
- 加血没有基础生命上限，可以超过卡牌初始生命值。
- 攻击力最低为0。减攻效果不能把攻击降到负数。
- 快攻：随从每回合可以攻击2次。
- 迅疾：上场当回合即可攻击。快攻与迅疾独立，可以叠加；同时拥有两者的随从上场当回合可攻击2次。
- 嘲讽：有嘲讽随从在场时，攻击必须优先选择嘲讽随从；并不强制每回合必须发动攻击。
- 狂妄：无视嘲讽，可以选择其他合法攻击目标。
- 亡语：随从死亡后发动其对应技能。献祭属于死亡，因此会触发亡语。
- 守护：抵挡1次伤害，无论该次伤害数值多高均完全免疫，随后消耗1次守护。守护只免疫伤害，不抵挡特殊效果。

### 2.5 通用关键词与状态

- 甲一／甲二：分别表示每次受到伤害时固定减1／减2。可与其他减伤效果叠加。
- 吸血：造成伤害的同时，使用者回复等量生命。
- 汲取：目标失去对应生命，同时汲取者回复等量生命。
- 灵体：不受效果卡影响；但“驱逐”的优先级高于灵体，因此驱逐可以作用于灵体。
- 隐匿：随从不主动攻击时无法被直接选中；但仍可被效果卡的范围／波及效果影响。
- 侦察：可以直接攻击隐匿随从。
- 必中：可命中具有闪避、无法被正常选中等规避机制的目标。
- 必杀：目标死亡后无法复活，优先级高于所有复活机制。
- 沉睡：使对方随从下回合不能行动；其技能仍可按自身规则存在／触发。
- 冰冻：使对方随从下回合不能行动；其技能仍可按自身规则存在／触发。
- 石化：使对方随从下回合不能行动，且石化期间技能无效，不能主动使用，也不会触发。
- 多属性随从同时属于所有标注属性，可以享受、触发全部对应属性效果与条件。
- 冷却N回合：技能使用后，接下来自己的N个回合均不能再次发动，到第N+1个自己的回合恢复。例如冷却2回合，则连续两个自己的回合不能使用，第三个自己的回合恢复。

### 2.6 武器、装备与场景

- 武器可以直接装备。每方最多同时装备1件装备；装备新的同类卡时，旧装备直接进入弃牌堆。
- 武器耐久度就是剩余使用次数，不是两个独立数值。武器每回合正常最多攻击1次，特殊效果可以突破限制。
- 武器每次攻击按牌面伤害及特殊效果结算，攻击同样受到嘲讽限制；没有目标限制时可以攻击敌方随从或英雄。
- 场景卡每方最多同时存在1张。场景卡有生命值，可以被攻击破坏；使用后，对应属性的随从获得牌面规定的增幅。
- 已有场景时可以使用新场景替换，旧场景直接进入弃牌堆。
- 武器耐久耗尽后的处理、场景被破坏后的增幅失效时点及部分场景目标规则，仍按后续牌面补充。

### 2.7 已知卡牌类别与系列

- 已知存在普通攻击牌、特殊能力牌、随从牌、武器／装备牌、场景牌、陷阱牌，以及进化石等相关卡牌。具体牌面限制以后逐张录入。
- 史前巨兽、洪荒异兽均是随从系列，不是新的卡牌类型。
- 史前巨兽系列：召唤该系列随从均需先消耗1颗进化石，再满足该卡自身的召唤条件。
- 洪荒异兽系列：召唤该系列随从均需先消耗1颗进化石，再满足该卡自身的召唤条件。
- 系列通用进化石要求不代表必须另有前置随从。只有牌面明确写了前置随从时，才增加该要求。
- 龙神系列：默认召唤需要1颗进化石，再满足卡牌自身条件；牌面明确写“无需进化石”或要求2颗进化石时，以牌面为准。
- 先天之灵：游戏内最强系列之一。一只先天之灵在场时，对方全体随从-1伤；该系列效果不压制无上后贤。
- 无上后贤：与先天之灵平级的顶级系列。无上后贤在场时，己方其他随从+1伤，不包括自身；该系列效果不作用于先天之灵。
- 先天之灵与无上后贤不会通过各自的系列级±1伤机制互相压制。
- “先天之灵”和“无上后贤”后续卡牌通常具有复杂召唤链、形态、特殊血条、技能优先级或专属装备等机制，不能按普通随从模板简化。

### 3.10 先天之灵（C076）

先天之灵是游戏内最强系列之一。已确认系列效果：一只先天之灵在场时，对方全体随从-1伤；与无上后贤之间不会互相压制对方系列。

#### C076 祖龙
- 系列：先天之灵
- 特殊血条属性：火、水、雷、普通、自然、器、归源
- 特殊血总量：12，其中归源6血，其余6种属性各1血。
- 召唤：献祭1只龙神，并扣6血召唤。
- 效果：守护。
- 效果：狂妄。
- 创世神体：拥有盾形态与攻形态，两形态切换后需冷却1回合才能再次切换。

**盾形态**
- 使用7种特殊血条。
- 每回合3伤。
- 只有对应属性随从的攻击才能打掉对应属性的特殊血条。
- 特殊血条不能回复。
- 盾形态不能使用下列6种能力。

**攻形态**
- 使用普通血量体系。
- 每次从盾形态切换到攻形态时，普通血量会重新按照盾形态“当前剩余特殊血总量”变满。
- 因此，攻形态受到的伤害不会永久损失祖龙的特殊血。例如盾形态仍剩12特殊血，攻形态即使只剩1血，切回盾形态后特殊血仍按原状态存在；再次切入攻形态时又会回到12普通血。
- 只有在盾形态真正打掉特殊血，才会永久降低之后攻形态可恢复到的血量。
- 攻形态可使用以下6类能力；单回合可以选择多个，但同一种单回合不可重复。每次使用扣3血。

**六类能力／联动**
1. 对方减4攻，持续1回合；并造成5点伤害。
2. 与效果卡“超高压雷电”联动：加2伤。该效果卡本身不属于祖龙自带技能。
3. 与效果卡“增幅爆炸”联动：加2伤。该效果卡本身不属于祖龙自带技能。
4. 造成8点伤害。
5. 造成5点伤害，并使对方武器耐久每回合减2。
6. 3点治疗；治疗增加的是普通血量，不能恢复特殊血条。

## 5. 待确认与尚未定义的机制

以下只记录缺口，不代表要增加新规则。正式编程时应区分“未定义”与“已经确认”，不允许为了让程序运行而悄悄补入其他游戏的机制。

### 5.1 对局与通用结算

以下底层规则已在v0.5封入Rules Core v1，不再列为缺口：5个常规随从位、经典共享总牌库、后手首次摸5张及额外普通进化石、双方开局超级进化石、牌库抽空后洗回弃牌继续抽、进化场上前置与不限次数、献祭算死亡并触发亡语、双方弃牌堆独立、亡语顺序、攻击最低0、甲一／甲二、吸血／汲取、灵体、隐匿、侦察、必中、必杀、沉睡／冰冻／石化、多属性、冷却计时及当前回合优先结算原则。

仍需以后补充的通用问题：
- 先手的具体决定方式仍未定义。
- 共享牌库抽空后“已弃掉的牌”重新洗回时，是否合并双方弃牌堆、如何保留卡牌归属与死亡历史，需要程序实现前确认。
- 进化成功后原卡进入弃牌堆已经确认，但进化是否算死亡、是否触发亡语尚未被用户单独明确。
- 特殊效果临时突破5只随从位时的UI排布与回落方式；忍者分身已明确不占上限。
- 武器耐久耗尽后的处理，场景被破坏后的增幅处理及部分场景攻击限制。
- 治疗型随从的“治疗”主动使用方式、次数等仍需逐卡确认；“加血无上限”已经确认。
- 同时涉及减伤、守护、免疫、不可无视、必杀等更高优先级效果时，仍需随着高级卡牌继续建立统一优先级表。
- 卡牌数量未提供者仍未确认，不能根据当前记录推算完整牌库张数。
