### Hard rules

1. 正式卡背不得重新生成、加字、改变中央徽记或恢复上下突出长尖角。
2. 结束回合机关不得改回网页按钮式大色块；必须保持“嵌在战场右侧结构中的机关”。

4. 大量牌只用四层视觉厚度抽象；最后四张才一张一张真实减少。
5. 这些资产不改变游戏规则，只改变表现层。
